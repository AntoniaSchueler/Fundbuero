# Fundbüro am Katharineum – ohne Supabase

Streamlit-App für Fundsachen mit Teachable-Machines-KI.

Keine Supabase-Zugangsdaten und keine Benutzerkonten für Nutzer erforderlich.

In Streamlit Cloud als Main file `Code_Fundbuero.py` auswählen.

Optional in Streamlit Secrets:
```toml
ADMIN_CODE = "DEIN_GEHEIMER_CODE"
```
